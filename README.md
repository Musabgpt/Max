# MAX — مساعد Android بالعربية

تطبيق Android أصلي للمحادثة والصوت والذاكرة المحلية، مع أدوات هاتف تُنفّذ بعد
المراجعة، ومتصفح، وإشعارات واتساب والبريد، ومهام نصية مجدولة.

**هذه نسخة أولى قابلة للتثبيت، وليست نظامًا يملك جميع صلاحيات الهاتف تلقائيًا.**
Android يتطلب موافقة المستخدم، ولا يسمح للتطبيق بتجاوز قفل الشاشة.

**[⬇ تحميل APK التجريبي (9.5 MB)](https://github.com/Musabgpt/Max/raw/refs/heads/main/apk/MaxAssistant-v1.apk)** ·
[نتائج التحقق](docs/qa/build-verification.json) · [SHA256](apk/SHA256SUMS.txt)

## البدء

1. ثبّت `MaxAssistant-v1.apk` على هاتف Android 8 أو أحدث بمعمارية ARM64.
2. اختر «ابدأ مجانًا» لتنزيل النموذج المحلي مرة واحدة (~491 MB، دون حساب أو مفتاح)،
   أو «إعداد NVIDIA» لفتح صفحة المزود وإدخال مفتاح API مرة واحدة.
3. فعّل الصلاحيات التي تحتاجها فقط من الإعدادات. يتطلب التحكم خدمة الوصول؛
   الوارد والردود يتطلبان الوصول إلى الإشعارات؛ الصوت يحتاج الميكروفون.
4. شغّل «العمل بالخلفية» وجدول مهمة، أو اختر وضع النوم لتأجيل تنفيذ المهام.

في بعض هواتف Android 13+ يجب أولًا فتح معلومات التطبيق، ثم السماح بالإعدادات
المقيّدة، حتى تتمكن أنت من تفعيل خدمة الوصول/الإشعارات لتطبيق مثبّت من APK.
المتصفح الداخلي يحتاج Android System WebView أو Chrome المدعوم مفعّلًا؛ عند
غيابه تظهر إرشادات مع خيار فتح الرابط في متصفح خارجي، دون تعطل التطبيق.

## ما يعمل وما حدوده

| الميزة | التنفيذ الحالي |
| --- | --- |
| ذكاء مجاني دون API | Qwen2.5 0.5B Instruct محلي عبر llama.cpp. تنزيل 491,400,032 بايت مرة واحدة، والتحقق من SHA256. نموذج صغير ذو قدرات محدودة؛ الطلب المحلي حتى 700 حرف. |
| NVIDIA | HTTPS OpenAI-compatible، معرّف نموذج قابل للتعديل، مفتاح مشفّر بـAndroid Keystore. المجانية والحصة والتوفر تحددها NVIDIA؛ لا مفتاح مشترك مضمّن. |
| ذاكرة الهاتف | SQLite خاص بالتطبيق للمحادثات والذكريات والمهام والوارد. الذكريات المحفوظة تدخل سياق النموذج المختار؛ عند اختيار NVIDIA تُشارك معه. |
| التحكم بالهاتف | فتح WhatsApp/Gmail/Chrome/Outlook، الضغط على نص، كتابة في حقل غير سري، رجوع وتمرير. مراجعة واضحة وصلاحية وصول، مع التحقق من التطبيق المستهدف وفتح القفل. |
| المتصفح والنماذج | HTTPS وJavaScript، اختيار حقل وملؤه دون إرسال النموذج. حقول كلمات المرور والدفع مستثناة، ولا جسر JavaScript إلى صلاحيات Android. |
| البريد وواتساب | التقاط إشعارات WhatsApp وWhatsApp Business وGmail وOutlook الجديدة؛ ليست مزامنة لكامل البريد أو سجل المحادثة. الرد المباشر متاح فقط أثناء صلاحية الإشعار ودعم RemoteInput وبعد مراجعة النص. |
| إرسال بريد | مسودة بمستلم وموضوع ونص داخل تطبيق البريد المثبت؛ التطبيق المثبت يتولى الحساب والإرسال النهائي. |
| الطيران والقطارات | فتح بحث رحلات/قطارات في المتصفح؛ اختيار الرحلة والتحقق من السعر وإتمام الحجز والدفع لدى المزود بيد المستخدم. لا شراء تلقائي ولا تأكيد حجز وهمي. |
| الخلفية والشاشة مطفأة | خدمة أمامية بإشعار ظاهر + JobScheduler لتجهيز نتائج نصية في الموعد، حسب قيود Android والبطارية. لا تحكم بالشاشة أثناء القفل، ولا عمل عند إطفاء الهاتف بالكامل. |
| النوم والعمل | النوم يؤجل المهام؛ العودة للعمل تستأنف فحص المهام المستحقة. الإيقاف يمنع بدء مهمة جديدة. المواعيد تقريبية وليست إنذارات دقيقة. |
| الصوت | تعرّف عربي يبدأ بالضغط، وقراءة اختيارية للإجابات. توفر العربية والعمل دون إنترنت يعتمدان على خدمات الصوت المثبتة؛ لا استماع مستمر بالخلفية. |

أمثلة أوامر: `افتح واتساب`، `افتح موقع https://example.com`، `اضغط على التالي`،
`اكتب في الحقل اسمي`، `مرر للأعلى`، `رجوع`. طلبات مثل «اكتب مسودة رد» تولّد نصًا.
لا تُنفّذ مخرجات النموذج كأوامر برمجية أو إجراءات هاتف.

## الخصوصية

- المفتاح لا يدخل SQLite أو المحادثات، بل يُشفّر بـAES-GCM بمفتاح Android Keystore.
- لا إرسال تلقائي لسجل الإشعارات إلى المزود؛ إنشاء مسودة من إشعار يتطلب طلبًا واضحًا.
- ملفات التطبيق مستثناة من النسخ السحابي ونقل الجهاز. يمكن حذف المحادثة والذكريات
  وسجل الإشعارات والمفتاح من الواجهة، أو مسح كل بيانات التطبيق من Android.
- المتصفح يحتفظ بجلسات المواقع داخل WebView الخاص بالتطبيق. لا تجاوز لشهادات TLS
  أو CAPTCHA أو تسجيل دخول المواقع. تجنب حفظ أسرار أو بيانات دفع في الذاكرة النصية.
- لا يوجد خادم خاص أو حساب MAX أو تحليل استخدام مضمّن.

## البناء

يلزم JDK 17، وAndroid SDK 35، وBuild Tools 35.0.0، وNDK 27.2.12479018،
وCMake 3.22.1. Gradle 8.11.1 وAGP 8.9.3 مثبّتان بإصدارات محددة.

```bash
git clone --recurse-submodules https://github.com/Musabgpt/Max.git
cd Max
# اضبط JAVA_HOME وANDROID_HOME حسب تثبيت Android Studio
. scripts/android-env.sh
sh scripts/bootstrap-android.sh
./gradlew --no-daemon testDebugUnitTest lintDebug assembleDebug
```

الإخراج: `app/build/outputs/apk/debug/app-debug.apk`. نسخة debug موقعة بمفتاح
تطوير محلي، للاختبار والتثبيت المباشر؛ النشر يتطلب مفتاح إصدار خاص بك ومراجعة
سياسات متجر التطبيقات، خصوصًا AccessibilityService وforeground specialUse.
لا تضع مفاتيح التوقيع أو API داخل Git. APK يشمل ARM64 وx86_64 للاختبار، ولا يشمل ARM32.

يعتمد CMake على submodule llama.cpp عند commit
`ec7f3ac9ab33e46b136eb5ab6a76c4d81f57c7f1` (b4514)، مع سياق 2048 token.
النموذج يُنزّل من revision
`9217f5db79a29953eb74d5343926648285ec7e67`؛ SHA256:
`74a4da8c9fdbcd15bd1f6d01d621410d31c6fc00986f5eb687824e7b93d7a9db`.
أبقِ التطبيق مفتوحًا أثناء تنزيله؛ الإلغاء يحذف الملف الجزئي وتبدأ المحاولة التالية من جديد.

## الاختبارات

اختبارات JVM تغطي توجيه الأوامر، فصل كتابة المسودات عن تعبئة الحقول، وحدود
الروابط والإدخالات. `lintDebug` و`assembleDebug` يتحققان من APK والواجهات الأصلية.
أدلة المحاكي والقيود المرصودة محفوظة تحت [docs/qa](docs/qa).
لا تعتبر اختبارات المحاكي تحققًا من وصول حسابات Gmail أو WhatsApp الفعلية
أو حصة NVIDIA؛ هذه تحتاج حسابات المستخدم وجهازه وصلاحياته.

## المكونات

- `MainActivity`: واجهة عربية أصلية ذات خمس صفحات.
- `data`: تخزين محلي ومفتاح مشفّر.
- `ai`: نموذج محلي، تنزيل متحقق منه، NVIDIA، وموجّه أوامر صريح.
- `automation`: وصول، مراجعة إجراءات ومتصفح ونماذج.
- `service`: التقاط إشعارات، ردود RemoteInput وجدولة العمل/النوم.
- `.m1`: حالة التقدم وقرارات التنفيذ، دون مفاتيح أو بيانات مستخدم.
