# MAX1.1.0 · نسخة تجريبية

[تحميل APK مباشرة](https://raw.githubusercontent.com/Musabgpt/Max/v1.1.0-preview.1/apk/MaxAssistant-v1.apk)

ثبّت التحديث فوق النسخة السابقة **دون حذف التطبيق**. الإصدار يحمل نفس التوقيع؛
اختبار Android الفعلي أكد بقاء المفتاح المشفّر والذاكرة والمحادثات بعد التحديث.

- `افتح تطبيق فيسبوك وانشر مرحبا`: خطة تُراجع أولًا، ثم تجهيز مسودة داخل التطبيق
  مع إلغاء ظاهر وتأكيد منفصل قبل النشر. كذلك واتساب مع مستلم ونص محددين.
- `اكتب كود الة حاسبة html وشغله`: حاسبة تعمل داخل معاينة HTML دون نموذج أو API.
  المعاينة تحفظ الكود وتعرضه وتنسخه، وتمنع الشبكة والملفات وأذونات الهاتف.
- معالجة الردود الفارغة و`null`، مع محاولة محدودة للجواب الذي توقف بسبب حد الطول.
- لغة عربية محددة للصوت، دون فرض العمل دون إنترنت، ومحاولة واجهة النظام البديلة
  عند عدم دعم اللغة. الكلام يبقى مسودة للمراجعة.

يتطلب التحكم تفعيل خدمة الوصول من إعدادات Android وفتح القفل. واجهات التطبيقات
قد تختلف؛ هذه ليست مزامنة لكامل سجل واتساب أو البريد. خدمات الصوت تحتاج محركًا
يدعم العربية. لا تحكم بالشاشة أثناء القفل ولا تشغيل عند إطفاء الهاتف بالكامل.

البناء وفحص GitHub و69 اختبار JVM نجحت. أدلة Android وحدود الاختبارات في
[مجلد QA](https://github.com/Musabgpt/Max/tree/v1.1.0-preview.1/docs/qa/max11).
نجحت15 حالة Android مميزة، مع فحص إعداد بيانات التحديث وفحص ظهور مسودة الصوت.
اختبارات النشر والرسائل تستخدم تطبيقات تجريبية محلية، دون حسابات أو إرسال فعلي.
